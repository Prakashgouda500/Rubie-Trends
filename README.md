# 🛍️ Rubie Trends – E-Commerce Web Application

**Rubie Trends** is a modern eCommerce web application designed to provide a seamless online shopping experience. Users can browse, search, and purchase a wide range of electronic products including mobiles, laptops, audio devices, watches, and tablets.

---

## 🚀 Features

* 🛒 Browse products by category (Mobiles, Laptops, Audio, Watches, Tablets)
* 🔍 Search and filter products easily
* 🛍️ Add to cart and manage cart items
* 💳 Order placement and receipt generation
* 📱 Responsive design for desktop and mobile
* 🔐 OTP-based authentication (Firebase integration)
* 🧾 Download order receipt (PDF)

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js
* **Database:** MySQL
* **Authentication:** Firebase OTP Verification
* **Tools:** VS Code, Git, Browser

---

## 📦 Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Prakashgouda500/rubie-trends.git
   ```

2. Navigate to the project folder:

   ```bash
   cd rubie-trends
   ```

3. Open in browser:

   ```
   http://127.0.0.1:5000
   ```
